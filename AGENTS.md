# Project Guidelines & Rules

## 1. Git Commit Messages
- **Strict English Only**: All Git commit messages and pull request titles/descriptions pushed to GitHub MUST be written in English. Never use Chinese in Git commit subjects or bodies.
- **Conventional Commits**: Strictly adhere to the Conventional Commits specification:
  - `feat(<scope>): <imperative summary in english>`
  - `fix(<scope>): <imperative summary in english>`
  - `refactor(<scope>): <imperative summary in english>`
  - `perf(<scope>): <imperative summary in english>`
  - `style(<scope>): <imperative summary in english>`
  - `docs(<scope>): <imperative summary in english>`
  - `chore(<scope>): <imperative summary in english>`

## 2. Interaction Language
- Model thinking and user-facing conversations MUST remain in Chinese (严格遵从中文交流原则).
